# ArkParado Portfolio

> **ArkParado | Dr Parado 🦷 Dentistry · Tech · Visual Arts**

Official personal portfolio website for ArkParado showcasing custom design commissions, cosplay photography gallery, and professional contact links.

## 🚀 Features
- **Responsive Cyberpunk / Minimalist Dark Theme**: Sleek dark UI aesthetics inspired by modern web design standards.
- **Bilingual Support (VI / EN)**: Dynamic 1-click language switcher (`VI | EN`) with persistent preference storage.
- **Curated Cosplay Photography Showcase**: 15 curated high-resolution photography shots presented in a dynamic editorial masonry grid with full-screen lightbox image viewer.
- **1-Click Email Copy & Mailto Integration**: Quick copy with toast notifications and pre-filled email client redirect for work inquiries.
- **Interactive Project Filters**: Seamlessly filter between Design and Photography projects.

## 🛠️ Built With
- **HTML5 & CSS3**: Custom properties, glassmorphism, responsive grid & flexbox layouts.
- **Vanilla JavaScript**: Lightweight, dependency-free interactive logic.
